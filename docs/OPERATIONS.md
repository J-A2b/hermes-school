# Exploitation

Consultez [INSTALLATION.md](INSTALLATION.md) pour l’installation, les services, l’accès distant, les sauvegardes et la restauration.

Une commande peut échouer avant l’enregistrement d’un `sync_run`, notamment pendant l’authentification. Vérifier le compte système, le répertoire de données et la configuration avant de relancer le login interactif. Les exceptions distantes sont volontairement résumées pour éviter d’exposer des secrets.

Pour un problème persistant, fournir une reproduction synthétique et le type d’erreur. Ne jamais publier une base réelle, des identifiants, un token, une clé ou un journal non expurgé.
